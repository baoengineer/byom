    Claude can call them too.
    
          
    Each session loads a small skill and one subagent per model. Ask for a second opinion from GPT or a cheap pass from a fast model, and Claude sends the work there. byoclaude models --json tells it what each model costs and whether it is ready.
    
        
    
        
    
          
    claude · ~/myappOpus
    
          
    
            ❯ review the staged diff, and get a second opinion from GPT
            
    ● Agent(byoclaude:openai-gpt-5-6-sol)
    
            
    ⎿ Review the staged diff in src/pool.rs for race conditions. Report file and line.
    
            
    ● Agent(byoclaude:groq-llama-3-3-70b-versatile)
    
            
    ⎿ List every caller of Pool::release in this repository.
    
            
    ● Both point at one issue: release() returns the socket to the pool before its state is cleared.
    
          
    
        
    
      
    
    
    

    
    
      
    
        
    
          
    Or ask a panel.
    
          
    When being wrong is costly, byoclaude panel puts the question to several models at once, on the plans you already pay for. Each one answers independently as a full Claude Code agent that can read the repo and run your tests. A judge from another provider compares the reports without seeing model names, and Claude gets the verdict.
    
        
    
        
    
          
    
            
    zsh · ~/myapppanel
    
            
    
              $ byoclaude panel "Is the retry logic in src/pool.rs safe under concurrent release?"
              
    panel: openai/gpt-6-astra, kimi/k3, deepseek/deepseek-v4-pro
    
              
    judge: claude-opus-5-5 (relay)
    
              
    3 panelists running · 3 reports · judging
    
              
    Agreement (all three): release() can return a connection to the pool twice when a retry races it.
    
              
    Conflict: does retry() need the pool lock?
    gpt-6-astra: yes, it reads idle before locking (src/pool.rs:88)
    k3: no, idle is only written under the lock
    Judge: gpt-6-astra is right; line 88 reads idle unlocked.
    
              
    Recommendation: take the lock before reading idle in retry(), and add a concurrent release test. Confidence: high.
    

    model                     time   tokens  cost

claude-opus-5-5 (judge)   1m20s  39k     plan

    byoclaude is an independent open-source project, not affiliated with or endorsed by Anthropic, OpenAI or any other provider. Each provider's plan limits and terms apply. It never imitates another client, reads other tools' credentials or pools accounts.
    
    
    Claude requests are relayed on Claude Code's own sign-in, as Claude Code sent them. Anthropic has not explicitly approved relaying subscription traffic through a local proxy; byoclaude says so on first run. Turn it off with byoclaude config set relay false.
